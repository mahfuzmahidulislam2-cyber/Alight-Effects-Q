# Alight Effects Q (AEQ) - Android project
Application ID: com.aeq.editor. WebView shell around the web app in app/src/main/assets/www.
Build: Android Studio (Hedgehog or newer, JDK 17) -> Build > Build APK(s), or `gradle assembleDebug` (Gradle 8.7+).
Output: app/build/outputs/apk/debug/app-debug.apk
Or push this folder to a GitHub repo: Actions > "Build debug APK" produces the APK as a downloadable artifact.
